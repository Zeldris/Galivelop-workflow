# 2026-11-27 · gw-worker · pending · E29

## Why

La revisión de 6531d0de dejó un hallazgo medio: el escaneo de commits seguía pasando la rama local en `--ref` y
`requireNames` lo juzgaba, así que `git push origin main:backup` sin lista se rechazaba como «could not run». Además
el mensaje aconsejaba `--no-names`, que el pre-push no puede pasar.

## Alternatives

- Que el escaneo no decida `requireNames` (solo `--names-required`): descartado, rompe el uso a mano
  `--range … --ref main`, que hoy falla cerrado.

## Changed because

`--dest BRANCH` (por defecto `--ref`) es lo que se compara con `protectedBranch`; el pre-push lo pasa con el destino y
deja `--ref` con la rama local para el `git rebase -i`. El mensaje pide la lista y volver a subir.
