## Why

El aviso de arranque saltaba en cada arranque en la nube por el sistema (prompt, herramientas, MCP), que el usuario no puede reducir.

## Alternatives

Clave nueva de umbral; restar el sistema siempre. Se reutiliza `systemAdvice` (D122) y solo se resta cuando el sistema es el mayor culpable.

## Changed because

Con `systemAdvice` activo el aviso y la alarma miden arranque menos sistema; bajo `warn`, una línea `Note` dice que no hay nada que recortar.
