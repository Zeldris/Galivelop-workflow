# D136 · `merge-branch.sh` y el worktree bloqueado por un agente vivo

## Goal

Que la limpieza de `merge-branch.sh` no falle con un worktree bloqueado (`git worktree remove` dice «cannot remove a
locked working tree»): lo distingue, lo dice y lo deja para una pasada posterior.

## Scope

`scripts/merge-branch.sh` y sus tests (recogida `0.9`, image-generator P5). No había mecanismo de «siguiente pasada»:
se deja el worktree y su rama, y el aviso da la orden para quitarlos a mano.

## Acceptance

- [x] Worktree bloqueado (con o sin motivo): fusionado, ni worktree ni rama se quitan, un aviso de una línea con
  `git worktree unlock <ruta> && git worktree remove <ruta> && git branch -d <rama>`, salida 0.
- [x] Worktree sin bloqueo: se quita como antes.

## Files

`scripts/merge-branch.sh`, `tests/test_utils.py` (`MergeBranch`), `docs/roadmap.md`, `docs/roadmap.en.md`.
