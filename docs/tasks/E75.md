# E75 · `grilling` guarda cada ronda antes de presentarla

## Goal

Que una ronda de `grilling` no viva solo en el chat: si la sesión se corta antes de la respuesta, se pierde y el
relevo no sabe qué se preguntó (recogida `0.9`, private-project-5 P3, retro `gw-0.8.0`).

## Scope

- `skills/grilling/SKILL.md`, sección «In a Galivelop-workflow project» (la única que cambia sobre el original): cada
  ronda se apunta en el archivo de preguntas con `questions.py add --refs <id> --rec …` (respuestas vacías), se hace
  commit con la bitácora nombrando sus `Q-<n>`, se sube con `push.sh` y solo entonces se presenta, numerada con esos
  ids; las respuestas, con `questions.py answer`.
- Copias generadas con `python3 scripts/apply.py .`.
