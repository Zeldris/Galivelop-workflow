## Why

`version.py` exigía un marcador en todo lo de `templates/`, también en los JSON de `templates/front` (sin sitio para un
comentario) y en un `node_modules` instalado, y ponía el check en rojo. El coordinador autorizó cambiarlo: solo cuentan
los archivos que git no ignora (ni `node_modules`), los JSON y el `.gitignore` de la plantilla van a `UNMARKED` con su
motivo y los `.ts` y el README llevan marcador. `apply.py` no recorre `templates/front` (solo carpetas concretas), así que
no cambia. El puerto del ejemplo sale de un socket libre y llega por `GW_SAMPLE_PORT` (el flaky de dos ejecuciones).

## Alternatives

Mover las plantillas fuera de `templates/` (rompe el lugar acordado); `git ls-files` (en el test el repo temporal no
tiene nada añadido).
