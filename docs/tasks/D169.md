# D169 · El pre-commit avisa si un scripts/ preparado difiere de su copia instalada

## Goal

Quien prepara un `scripts/X` sin pasar `apply.py .` lo sabe al commitear, no tras subir (antes D143, id repetido).

## Scope

`templates/githooks/pre-commit` y su copia `.githooks/`; clave `installedCopyWarn` (esquema, `config.md` es/en); tests.

## Acceptance

- [x] Un `scripts/<f>` preparado distinto de `.claude/gw/scripts/<f>` avisa en stderr (con `apply.py .`) y el commit sigue.
- [x] Igual o con `installedCopyWarn: false`, no avisa.
