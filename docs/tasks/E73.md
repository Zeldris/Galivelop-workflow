# E73 · Clave `projectSkillPrefix`: prefijo de las skills propias del proyecto

## Goal

Que las skills propias de un proyecto se distingan de las del flujo (`gw-`) por un prefijo declarado y comprobado
(recogida `0.9`, private-project-3 P4).

## Scope

- Clave nueva `projectSkillPrefix` (cadena, `""` por defecto; patrón: vacía o `[a-z0-9]+(-[a-z0-9]+)*-`, nunca `gw-`)
  en el esquema, la plantilla y `config.md` (es/en).
- `apply.py --init --project-skill-prefix <prefijo>` la escribe; el esquema rechaza `gw-`.
- `gw-init` (paso 3) y `apply.md` (es/en) la preguntan.
- `doctor.py`: aviso `skill prefix` por cada `.claude/skills/<nombre>/` cuyo `SKILL.md` no es copia del flujo
  (`metadata.source` no casa con `SOURCES`, la misma regla que `check_skills`) y cuyo nombre no lleva el prefijo, con
  el renombrado; OK si todas lo llevan; nada sin prefijo.
