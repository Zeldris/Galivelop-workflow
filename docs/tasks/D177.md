# D177 · handoff check avisa de pendientes abiertos que citan un id cerrado

## Goal

`handoff.py check` avisa de una entrada abierta (`- [ ]`) de `pendingFile` que cita un id del roadmap ya cerrado (retro 0.9, R2).

## Scope

`closed_id_problems` y `closed_roadmap_ids` en `scripts/handoff.py`, dentro de los avisos blandos (error con `--strict`); clave `pendingClosedIdCheck` (defecto true). Excepcion: la entrada que empieza por `Related: <id>` o el id escrito justo tras ver/see/see also/related. Este repo la pone en false: sus ~60 entradas de revision citan a proposito la tarea de origen.
