# B53 · red-without-fix.sh decide por ruta, no por contenido

## Goal

Que un archivo de código cuya docstring o prosa nombra un test ya no se rechace como código de test (recogida `2026-11-24`, usuario 2026-11-24).

## Scope

`scripts/red-without-fix.sh` y la clave `redWithoutFix` (esquema, plantilla, docs). Clave nueva `redWithoutFix.testPathRegex`; `testRegex` queda con marcadores anclados al inicio de línea.

## Acceptance

- [x] Una ruta que casa con `testPathRegex` se rechaza (exit 2) sin leer su contenido.
- [x] Una docstring o prosa que nombra un test en un archivo de código no lo rechaza.
- [x] Un marcador anclado (`#[test]`, `def test_`) en una ruta no-test sigue rechazándose.
- [x] Regex inválida de la clave: exit 2 con su nombre.

## Files

- `scripts/red-without-fix.sh`, `schema/gw.schema.json`, `templates/gw.json`, copias en `.claude/gw/`

- `docs/roadmap.md`, `docs/roadmap.en.md`, `docs/handoff.md`

## Change log

Se decidió por ruta (`testPathRegex`) y no por `testMap`: el mapa va de fuente a tests y no puede invertirse para reconocer un archivo de test. El contenido se conserva solo con marcadores anclados, para no perder los tests en línea (Rust).
